# Welcome to MY457/557

This is the GitHub organization (homepage) for MY457/557: Causal Inference for Observational and Experimental Studies at the London School of Economics.

The course website is [here](https://lse-my457.github.io/website/).

Course materials (slides and seminar materials) will be available in this GitHub organization during the term.

### Prerequisites

Students are expected to have sufficient knowledge of probability and statistics, including regression analysis (i.e., the equivalent of MY451 and MY452). Computational exercises will be done in R, so students are also expected to be familiar with the R programming language. Students with experience in Stata or Python can pick up the R skills necessary to complete this course if they are willing to put in the effort to do so.
